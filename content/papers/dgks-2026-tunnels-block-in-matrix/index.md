abstract: >-
  This paper presents an automated workflow linking a voxel-based
  block-in-matrix (BiM) ground model to PLAXIS 2D through its Python HTTP
  API, for finite element simulation of tunnel excavation in heterogeneous
  rock. Building on prior borehole-constrained ground model and conditional
  random field studies, it details the material models, excavation
  sequence and script logic used to transfer voxelized cross-sections into
  PLAXIS 2D, showing generally reduced but scattered radial displacements
  relative to a homogeneous deterministic model.
